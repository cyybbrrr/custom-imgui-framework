Font Awesome 7 is wired in CGui.cpp.

Place your local Font Awesome files in this folder using these exact filenames:
- Font Awesome 7 Free-Solid-900.otf
- Font Awesome 7 Free-Regular-400.otf
- Font Awesome 7 Brands-Regular-400.otf

The loader also searches a nearby plain "fonts" folder and common Visual Studio bin/Debug or bin/Release working directories.
The actual font files are not included in this zip.
